# Withdrawn synthetic spacecraft specification

**Status: withdrawn during the R0 credibility review.**

This file previously presented an unsourced hypothetical crew vehicle as a NASA spacecraft and asserted conformance with NASA, MIL, AIAA, and other standards. Those claims were unsupported. The vehicle, mission, dimensions, mass and power budgets, parts, materials, supplier names, work breakdown structure, performance estimates, and standards references in the former document must not be used for engineering, procurement, compliance, or program decisions.

No NASA authorship, approval, source baseline, independent reference data, or verification evidence is established for that content. The remaining aerospace visualization in this repository is synthetic geometry for interface demonstration only; it does not represent NASA hardware or a validated design.

See [data provenance](data_provenance.md), [known limitations](known_limitations.md), and the [industrialization status](industrialization/status.md) for current release evidence and remaining R0 gates.
